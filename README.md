# Emoji & Icon Hub

A fully static animated website for browsing, searching, copying and downloading emojis and SVG icons.

## Included

- `index.html`
- `styles.css`
- `app.js`
- Search + category filter
- Emoji copy + HTML entity copy
- SVG icon copy + HTML snippet copy
- SVG/PNG download for icons
- Favorites saved in localStorage
- Dark/light mode
- Mobile responsive layout
- Preloader, cursor glow, scroll reveal, 3D tilt, magnetic buttons, animated hero and progress bar

## Run

Extract the ZIP and open `index.html` in your browser.

## Add more assets

Open `app.js` and add more items to:

- `emojis` array for emojis
- `iconPaths` and `iconMeta` for icons
